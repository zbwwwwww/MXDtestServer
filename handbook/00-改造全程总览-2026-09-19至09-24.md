## 六 · 铁律（9 条，动手前必看）

1. **服务端加载编译产物，不是 src**：改 Java 必重编译 + 打包。`out\production\SERVER083`（IDEA）与 `out\artifacts\...jar`（`start-server.bat`）**两份都更新**。查加载哪份：`Get-CimInstance Win32_Process -Filter "name='java.exe'"` 看 `-classpath`。

3. **脚本 UTF-8 + 中文必须 GB2312 可编码**（封包硬编码 GB2312，不是 GBK）；**别写 emoji**。
4. **验脚本用 `jjs.exe`**（JDK8 Nashorn = ES5.1，无箭头函数 / `let` / `const` / 模板串）；路径 `C:\Program Files\Eclipse Adoptium\jdk-8.0.502.7-hotspot\bin\jjs.exe`。

7. **测试脚本 `action(1,0,N)` 的 N 绝不许写死** → 用 `*.length ± k` 相对表达。
