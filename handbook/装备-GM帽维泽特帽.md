## 核查过程与证据

1. **按名字搜**：1330 顶帽子里，名字含 `GM` / `管理员` / `客服` 的 —— **0 顶**。
   ⇒ 说明它的名字是「维泽特帽」，字面完全不含 GM，关键词搜不出来，这就是很多人找不到的原因。
2. **按 GM 级属性搜**：遍历 `Character.wz` 全部部位共 6107 件装备，`incSTR/DEX/INT/LUK ≥ 100` 的
   —— **只有 1002140 维泽特帽 1 件**（按原版值统计）。⇒ 它就是这服的 GM 装备。
   （配套的西装/西裤是纯外观，武器「维泽特特殊提包」另有 +200 物攻，见 `装备-超模装备清单.md`）
3. **模型完整性**：`01002140.img.xml` 13.4KB，含 stand/swing/stab/shoot/prone/heal/fly/jump/sit/ladder/rope
   全套动作帧 + `icon`(31×25) + `iconRaw`(31×19)。⇒ 是正式发布过的成品，不是半成品数据。
4. **服务端不限制**：全 `src` 搜 `1002140`，**无任何硬编码判定** ⇒ 服务端不会拒绝非 GM 玩家装备它。
5. **网上流传的其他 ID 不可信**：
   - 传言「1002186 = 蓝 GM 帽 / 1002187 = 红 GM 帽」——❌ 实测 **1002186 = 透明帽、1002187 = 蓝牛仔帽**，
     且都是现金物品（cash=1），与 GM 无关。该说法出自 SEO 内容农场，不要采信。
   - 「1002140 = GM 帽子」——✅ 与本地数据完全吻合。

## 注意事项

1. **属性很暴力**：四维 +32767 是 `short` 上限，戴上后四维直接爆表。
   GM 菜单「获取物品」的 `[GM套装(维泽特)]`、`[S档超模装备]` 两组都指向同一个 ID `1002140`，
   不会因为放进两个组就变成两件不同的装备。
2. **总值现在到 65534**：`characters` 表里 `ceshi` 的基础四维都是 **32767**（short 上限），
   再叠帽子的 +32767 ⇒ 面板总值 **65534**（= 2¹⁶−2，这套改法能安全到达的最高值）。
   服务端算伤害走 `int`，**没有问题**；你实测 9999（总值 42766）时已证明客户端不按 16 位**有符号**截断，
   而 65534 即便按**无符号 16 位**也装得下。仍建议上机扫一眼面板数字。
3. **客户端能否显示需上机实测**：客户端 `Character.wz`（1.15GB）是标准 `PKG1` 但做了防解包加密
   （`List.wz` 头部已非明文），离线无法确认节点是否存在。这是上机第一步要看的。
4. 该帽子 **未加交易锁**，且无等级/职业限制 —— 想给普通玩家发也没障碍。
