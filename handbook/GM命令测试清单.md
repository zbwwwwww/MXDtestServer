## 使用前提

| 项 | 说明 |
|---|---|
| 指令前缀 | **半角英文叹号 `!`** —— 客户端的 `/` 指令是坏的（会被当普通聊天发出），服务端不认 |
| 输入位置 | 游戏内的**聊天输入框**（敲完回车） |
| 回显位置 | 聊天框里的系统消息（黄色/紫色字） |
| 脚本类指令 | 若改了 `scripts/npc/*.js`，必须**完全关闭客户端再重开**才生效（脚本引擎按客户端缓存） |
| Java 类指令 | 若改了 `.java`，必须 **Build + 重启服务端** 才生效 |

## 二、NPC 菜单（射手村「冒险岛管理员」）

**位置**：射手村，坐标 x≈3650（左邻「彪鲁」爱心神官，右邻「库克斯」制果师）

**新的转职流程（两级点选）**：

```
[GM 功能菜单]
  └→ 修改职业（点选 / 输入编号）
        └→ [选择职业大系]
              战士系(10) / 法师系(10) / 弓手系(7) / 飞侠系(7) / 海盗系(7)
              └─ 直接输入职业编号   ← 老的兜底入口，保留
                  └→ [修改职业 - 战士系]
                       100  战士（一转）      111  勇士（三转）
                       110  剑客（二转）      112  英雄（四转）
                       ...
                       返回大系选择
```

点一下就转，**全程不用记编号**。

## 三、本轮要重点验证的 3 件事

| # | 验证点 | 判定标准 |
|---|---|---|
| 1 | **「满技能」是否修好** | 点它之后技能栏里当前职业技能**全部点满**；<br>且**点完还能再次打开 NPC 菜单**（之前会永久卡死） |
| 2 | **`!job` 带中文名** | 回显 `已转职：英雄 (112)` 而不是 `已转职，职业ID = 112` |
| 3 | **两级点选转职** | 不用打数字，点两下就转成功，并回显中文名 |

## 四、已知限制（不是 bug）

| 现象 | 原因 |
|---|---|
| 跨系转职后，旧职业技能还在技能栏、用不了也删不掉 | `changeJobById` 不做职业链校验，也不清理旧技能 |
| 转职不补等级、不补 SP | 四转职业在 10 级也能转，但打出伤害很低。建议先 `!exp` 升级 |
| `!maxskill` 只补**当前职业**技能 | 不会清理跨系残留的旧技能 |
| 没有回血/回蓝指令 | 服务端没有公开的 `setHp`/`heal` 接口，未实现 |
